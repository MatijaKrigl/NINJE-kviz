# NINJE – kviz

Datoteke za kviz, urejene v izvirne mape:

- `Prva naloga/`
- `Druga naloga/`
- `Tretja naloga/`, vključno s podmapo `TELLES_SAMODEJNO/`

Ohranjene so vse izvirne datoteke MATLAB, varnostne kopije `.asv`, besedilna navodila in PDF. Imena map in datotek ter njihova vsebina so ohranjeni brez sprememb.
